# Nobel Prize

A multi-page static website dedicated to the Nobel Prize — exploring its history, laureates, prizes, news, and gallery.

**Live Demo:** [https://nobel-prize.daniyal-khan.com/](https://nobel-prize.daniyal-khan.com/)
---

##  Pages

| Page | Description |
|------|-------------|
| `index.html` | Homepage with banner, highlights, and countdown |
| `nobelPrizes.html` | Detailed breakdown of each Nobel Prize category |
| `gallery.html` | Photo gallery |
| `aboutus.html` | About the Nobel Prize and its legacy |
| `contact.html` | Contact information form |

---

## Built With

- **HTML5** — semantic markup
- **CSS3** — custom styling with a golden theme (`#de9b2e`)
- **JavaScript (ES6)**
- [Bootstrap 5](https://getbootstrap.com/) — responsive layout and components
- [jQuery 3.3.1](https://jquery.com/) — DOM manipulation
- [Owl Carousel](https://owlcarousel2.github.io/OwlCarousel2/) — image sliders
- [Typed.js](https://mattboldt.com/demos/typed-js/) — animated text on banner
- [AOS (Animate on Scroll)](https://michalsnik.github.io/aos/) — scroll animations
- [jQuery Countdown](https://hilios.github.io/jQuery.countdown/) — countdown timer
- [Font Awesome 6](https://fontawesome.com/) — icons

## Features

- Fully responsive design (mobile, tablet, desktop)
- Animated hero banner with typed text effect
- Smooth scroll animations (AOS)
- Interactive image carousels (Owl Carousel)
- Nobel Prize countdown timer
- Laureate showcase section
- News and events section
- Image gallery
- Contact page
